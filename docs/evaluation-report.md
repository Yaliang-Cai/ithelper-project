## 结果核查

程序断言优先检查实际效果和状态；语义评分只是辅助证据。历史评分出现过误判，评测器修正后的重新断言单独保存在 [reassertions.json](../evals/public/reassertions.json)，受影响的旧评分不沿用为有效结论。[失败原文](../evals/public/failure-examples.md)保留便于追溯。

检索小样本中，有答案查询的关键词命中为 26/35，混合命中为 35/35；无答案查询均为 5/5。见[检索对照](../evals/public/retrieval.json)。这是同源合成数据上的命中比较，不是模型解决率或生产检索效果。
