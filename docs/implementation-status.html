本轮检查修正

  • 员工报告问题复发后，旧的恢复反馈曾可能再次被用于结案。现在复发症状会使较早反馈失效，新的明确恢复反馈仍可通过验收。
  • 同一问题再次执行解锁后，追加另一种指导曾沿用首次操作的反馈时间。现在以最近实际操作或尝试为准，要求该问题有更新的失败反馈。
  • 报告生成器曾把一次预留前被预算阻止的调用计为实际请求。现在分开统计尝试与账本请求，并按原批次固定历史结果分母，后续定向测量另列。

四项新回归在修复前失败、修复后通过；完整离线套件 218 项通过。修复限于现有验收与统计逻辑，没有新增服务、审批层或业务功能。本轮没有新增付费模型调用，实模结果对应以上修复前的代码。

仍然存在的问题

  1. 追问与结构化问题有时不一致。D05 可见问题只问页面范围，结构化问题还包含起始时间；当前测量没有覆盖下一轮回答。
  2. 回复仍会冗长或包含内部会话键。D09 的确认说明达 340 字，提示词约束没有完全解决表达问题。
  3. 最终提示词只复测两个已知案例，重复次数不足。此前五类场景的测量不能全部归给 v7，也没有最终版本的完整盲测。
  4. 程序能阻止不满足权限条件的操作，却不能证明诊断、指代和交接解释在语义上正确。同模型评分出现过误判，因此保留原文并单列无效评分。

优先补同一版本的多轮续问、失败复测与重复覆盖，再考虑新功能。生产化另需真实身份与业务接口、外部操作对账、专家接续和独立评审。
